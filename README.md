# 🚀 Interactive Projects & Prototypes

A collection of interactive WebGL/Three.js simulations, algorithm optimization tools, regulatory audit systems, and software implementations showcasing full-stack development, systems analysis, and engineering logic.

## 🌟 Featured Interactive Demos

### 1. Tariff Audit Desk – Electricity Tariff Verification & Batch Auditing Tool
- **Tech Stack:** JavaScript, HTML5/CSS3, Responsive UI/UX
- **Live Demo:** [View Tariff Audit Desk Simulation](Tariff_Audit_Desk.html)
- **Overview:** An interactive electricity tariff verification and batch auditing tool built to audit complex block tariffs, calculate billing discrepancies, and process multi-account billing runs.
- **Key Features:**
  - **Configurable Block Tariffs:** Dynamic block definition with customizable kWh ranges, rates, fixed charges, and VAT percentages.
  - **Single Account Inspector:** Deep-dive bill verification with itemized cost receipts and dynamic visual curves mapping consumption against tariff tiers.
  - **Batch Billing Runner:** Multi-account CSV/tab-delimited parsing engine with tolerance thresholds, automated KPI summaries, variance bar charts, and report export functionality.

### 2. Consultation Clock – Regulatory Deadline Tracker & Submission Drafter
- **Tech Stack:** JavaScript, HTML5/CSS3, LocalStorage API
- **Live Demo:** [View Consultation Clock Simulation](Consultation_Clock.html)
- **Overview:** An interactive regulatory deadline tracker and submission drafter designed to monitor public comment windows, track hearing schedules, and structure formal written regulatory submissions.
- **Key Features:**
  - **Timeline Visualizer:** 60-day interactive countdown timeline with urgency color-coding (red markers for notices closing within 7 days).
  - **Notice Manager:** Dynamic form interface to add, filter, and track public consultation notices across multiple regulatory categories.
  - **Structured Submission Drafter:** Real-time completeness meter and live preview generator that compiles position statements, evidentiary points, and clause-specific feedback into a copy-ready formal submission.

### 3. Settlement Core – High-Performance Betting Back-End & SQL Lab
- **Tech Stack:** C#, .NET, ASP.NET Core, Relational SQL, JavaScript, HTML5/CSS3
- **Live Demo:** [View Settlement Core Simulation](Settlement_Core.html)
- **Overview:** An interactive back-end architecture and API simulation built to demonstrate financial transaction integrity, validation pipelines, and relational database querying.
- **Key Features:**
  - **Idempotent API Design:** Handles duplicate requests safely using idempotency keys and secure replay logic.
  - **Cent-Safe Financial Calculations:** Prevents floating-point rounding errors by handling monetary math in integer cents.
  - **Risk & Liability Controls:** Automated rule checks enforcing maximum payout thresholds and validation boundaries.
  - **Live SQL Lab:** Fully executable SQL queries running over a seeded ledger of 3,000+ rows, featuring aggregations (GROUP BY, HAVING) and window functions.

### 4. Apex Live – Real-Time Race Simulation & Win Probability Engine
- **Tech Stack:** JavaScript, HTML5 Canvas, HTML5/CSS3, Responsive UI/UX
- **Live Demo:** [View Apex Live Simulation](Apex_Live.html)
- **Overview:** A real-time race simulation featuring live win probabilities, safety car deployment, and dynamic leaderboard animations rendered at native screen resolutions.
- **Key Features:**
  - **Canvas Graphics & Rendering:** Custom 2D render loop featuring high-performance particle trails, glowing gradients, and smooth coordinate scaling.
  - **Dynamic Softmax Probability Engine:** Computes real-time win odds based on car pace, remaining lap distance, and form fluctuations.
  - **Interactive Controls:** Adjustable race speeds, dynamic theme hue shifting, and safety car triggers.

### 5. Rosslyn Twin – Live Production Line Digital Twin
- **Tech Stack:** JavaScript, Three.js (WebGL), HTML5, CSS3
- **Live Demo:** [View Rosslyn Twin Simulation](rosslyn_twin.html)
- **Overview:** Interactive 3D digital twin simulation of a 6-station vehicle manufacturing line (Body Shop, Paint, Assembly, Marriage, Final, Quality).
- **Key Features:**
  - **Real-Time Flow Tracking:** Live calculation of throughput ceiling versus real-time vehicles per hour.
  - **Bottleneck Diagnosis:** Automated bottleneck detection and cycle-time reduction algorithms.
  - **Disruption Testing:** Dynamic simulation of supply shortages and component breakdowns.

### 6. Fahrlinie – Racing Line & Physics Optimization Tool
- **Tech Stack:** JavaScript, HTML5 Canvas, HTML5/CSS3
- **Live Demo:** [View Fahrlinie Circuit Tool](fahrlinie.html)
- **Overview:** Interactive physics-based tool that calculates optimal racing lines and lap times on user-drawn or preset circuits.
- **Key Features:**
  - **Vehicle Dynamics Model:** Point-mass model utilizing friction circle limits for combined braking and lateral grip.
  - **Path Relaxation Algorithm:** Vector optimization within track boundaries to maximize apex velocities.
  - **Telemetry Visualization:** Real-time G-force metrics, dynamic gear shifts, and telemetry data graphing.
