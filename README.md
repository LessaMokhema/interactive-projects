### 1. Tariff Audit Desk – Electricity Tariff Verification & Batch Auditing Tool
* **Tech Stack:** JavaScript, HTML5/CSS3, Responsive UI/UX
* **Live Demo:** [View Tariff Audit Desk Simulation](https://lessamokhema.github.io/interactive-projects/Tariff_Audit_Desk.html)[cite: 7, 9]

### 3. Settlement Core – High-Performance Betting Back-End & SQL Lab
* **Tech Stack:** C#, .NET, ASP.NET Core, Relational SQL, JavaScript, HTML5/CSS3
* **Live Demo:** [View Settlement Core Simulation](https://lessamokhema.github.io/interactive-projects/Settlement_Core.html)[cite: 2, 9]
* **Overview:** An interactive back-end architecture and API simulation built to demonstrate financial transaction integrity, validation pipelines, and relational database querying[cite: 2].
* **Key Features:**
  * **Idempotent API Design:** Handles duplicate requests safely using idempotency keys and secure replay logic[cite: 2].
  * **Cent-Safe Financial Calculations:** Prevents floating-point rounding errors by handling monetary math in integer cents[cite: 2].
  * **Risk & Liability Controls:** Automated rule checks enforcing maximum payout thresholds and validation boundaries[cite: 2].
  * **Live SQL Lab:** Fully executable SQL queries running over a seeded ledger of 3,000+ rows, featuring aggregations (`GROUP BY`, `HAVING`) and window functions[cite: 2].
